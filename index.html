GitHub Actions

The Ultimate Masterclass

A visual journey into automating your workflows, optimizing CI/CD pipelines, and shipping code faster.

Why GitHub Actions?

The industry standard for modern automation.

  • Native Integration: Built directly into GitHub. No webhooks required.
  • Zero Infrastructure: GitHub hosts Linux, Windows, & macOS runners.
  • Event-Driven: Trigger on PRs, issues, releases, and more.
  • Marketplace: 20,000+ plug-and-play actions available instantly.

GitHub Actions vs. Jenkins

Legacy Tools

  • Requires dedicated VMs to host and maintain.
  • Plugin Hell: Constant dependency updates.
  • Complex Groovy script pipelines.
  • Isolated from code repositories.

GitHub Actions

  • Serverless: Fully managed cloud instances.
  • YAML syntax: Clean, standardized, easy to review.
  • Seamless enterprise-grade security & secrets.
  • Executes precisely where developers collaborate.
Scenario 01

Basic CI Pipeline

Automatically test your code on every push or Pull Request.

View Full Workflow YAML 

on:
  push:
    branches: [ "main" ]
  pull_request:
    branches: [ "main" ]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - run: npm install
      - run: npm test
Scenario 02

Scheduled Jobs (Cron)

Automate background jobs like daily database backups or midnight health checks.

View Full Workflow YAML 

on:
  schedule:
    # Runs every day at 12 PM UTC
    - cron: '0 12 * * *' 

jobs:
  daily-backup:
    runs-on: ubuntu-latest
    steps:
      - name: Run script
        run: ./scripts/run_backup.sh
Scenario 03

Manual Trigger

Give your team a visual UI to trigger deployments or maintenance scripts on-demand.

View Full Workflow YAML 

on:
  workflow_dispatch:
    inputs:
      env:
        description: 'Target Environment'
        required: true
        default: 'staging'
        type: choice
        options: [staging, production]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - run: echo "Deploying to ${{ inputs.env }}!"
Scenario 04

Matrix Strategy

Multiply your productivity. Test your app across multiple operating systems in parallel.

View Full Workflow YAML 

jobs:
  test:
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]
        node: [18, 20]
    steps:
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node }}
      - run: npm install
      - run: npm test
Scenario 06

Docker Publish

Build and push your container images to DockerHub seamlessly on every new tag.

View Full Workflow YAML 

steps:
  - name: Login to DockerHub
    uses: docker/login-action@v3
    with:
      username: ${{ secrets.DOCKER_USER }}
      password: ${{ secrets.DOCKER_PAT }}
      
  - name: Build and Push
    uses: docker/build-push-action@v5
    with:
      context: .
      push: true
      tags: myorg/myapp:${{ github.ref_name }}
Scenario 11

Dependency Caching

Drastically reduce your build times by caching massive `node_modules` folders.

View Full Workflow YAML 

steps:
  - uses: actions/checkout@v4
  - uses: actions/cache@v4
    with:
      path: ~/.npm
      key: npm-${{ hashFiles('package-lock.json') }}
      restore-keys: |
        npm-
        
  - run: npm install
